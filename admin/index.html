Configuration requise

  1. Créer le projet Supabase et exécuter supabase/schema.sql.
  2. Configurer assets/config.js avec l’URL et la clé publique Supabase.
  3. Créer le premier compte dans Supabase Auth, puis lui attribuer le rôle administrateur depuis un environnement SQL fiable.
  4. Connecter les opérations CRUD à l’API avec vérification des permissions et tests RLS avant de publier.

Cette interface est le squelette du tableau de bord : elle ne prétend pas effectuer des opérations administratives tant que le backend n’est pas configuré.
